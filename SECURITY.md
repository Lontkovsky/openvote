# Security policy

This is test development software, not approved for real elections or politically sensitive participation. There is no completed independent audit and no paid bounty programme.

Report vulnerabilities through GitHub private vulnerability reporting for this repository: use **Security → Report a vulnerability**. Do not open public issues with exploit details, personal data or active secrets. If that option is unavailable, do not post sensitive details publicly; report the missing channel as a non-sensitive repository issue.

Scope: this repository's application, cryptographic integration, deployment configuration, public verifier and observer. Use local test fixtures only. Do not test third-party providers, infrastructure you do not own, or other participants. No denial-of-service testing against public deployments. Acknowledge, reproduce locally, coordinate remediation and publish a redacted advisory after remediation. No response-time guarantee is claimed while maintainership is voluntary.
